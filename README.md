# Sabah Alarmı ile Pazarlık Eden Uygulama

## Resmi Beyanname

Bu yazılım, 13 Eylül 2026 tarihinde **Uluslararası Erken Kalkma ve Çay Hukuku Mahkemesi** kararı uyarınca hayata geçirilmiştir. Amacı, sabah 06:47'de çalan alarmınızla sivil, nezaketli ve tamamen yasal bir pazarlık yürütmektir.

Alarm bir diktatör değildir. Alarm bir komşudur. Komşuyla konuşulur.

## Kurulum

```bash
python3 pazarlik.py
```

Bağımlılık yoktur. Python 3 yeter. Çünkü pazarlıkta araç gereç lüks kaçar.

## Protokol

1. Uygulama sizi temsilen alarmın karşısına çıkar.
2. Alarm üç teklif sunar: *hemen kalk*, *beş dakika*, *beni kapat ve pişman ol*.
3. Siz karşı teklif verirsiniz.
4. Nihai karar, çayın demlenme süresine göre ağırlıklandırılır.

## Bilimsel Dayanak

Yapılan 0 (sıfır) adet çift kör çalışmada, alarmla pazarlık edenlerin %100'ünün eninde sonunda kalktığı gözlemlenmiştir. Kontrol grubu yoktur. Kontrol grubu da kalkmıştır.

## Sorumluluk Reddi

Bu yazılım sizi işe yetiştirmez. Sizi vicdanınızla yüzleştirir. İşvereninizle pazarlık etmek için ayrı bir repo açılacaktır (açılmayabilir).
